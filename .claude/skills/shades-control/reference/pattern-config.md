# `pattern` store — GlobulePatternConfig

Store: `patternConfigStore` (`src/lib/stores/globulePatternStores.ts:15`). Type:
`GlobulePatternConfig` (`src/lib/types.ts:1446`):
`{type, id, name?, cutoutConfig, patternConfig, patternViewConfig, patternTypeConfig}`.
Default: `generateDefaultGlobulePatternConfig` (`src/lib/shades-config.ts:739`).

## What re-runs pattern generation

The worker regenerates 2D patterns only when `patternGenerationConfig` changes
(`globulePatternStores.ts:44-62`). That config contains:
`patternTypeConfig`, `patternConfig.pixelScale`, `patternViewConfig.showBands`,
`patternViewConfig.range`, `patternViewConfig.patternSource`, `patternConfig.splits`.
Any other field (pageLayout, postProcess, zoom, showQuads, …) is applied at render
or export time. Changing it does not regenerate.

A pattern change never re-runs 3D geometry. Pattern generation is skipped when
`computationMode === '3d-only'`, while paused, or in manual mode with pending
changes (`superGlobuleStores.ts:573-597`).

### `patternSource` → tubes (`src/lib/collect-rendered-points.ts:18-25`, `src/lib/cut-pattern/pattern-generation-gates.ts:40`)

| Value               | Tubes used                                                                                   | Needs gate                         |
| ------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------- |
| `globule`           | `superGlobule.globuleTubes`                                                                  | `view.showGlobuleTubeGeometry.any` |
| `projection`        | `projections[0].tubes` (cross-section tubes)                                                 | `view.showProjectionGeometry.any`  |
| `surfaceProjection` | `projections[0].surfaceProjectionTubes` (strips on the surface between edge and inset curve) | `view.showProjectionGeometry.any`  |
| `voronoi`           | `voronoiResult.tubes`                                                                        | `view.showVoronoiGeometry.any`     |
| `voronoiSurface`    | `voronoiResult.surfaceProjectionTubes`                                                       | `view.showVoronoiGeometry.any`     |

**Gotcha:** the default view enables only Voronoi, and the default source is a
projection one. A fresh load therefore gives an **empty pattern pane**. Set
`patternViewConfig.patternSource` to `'voronoi'` or `'voronoiSurface'`, or turn on
the matching gate.

## `patternTypeConfig` — which pattern

`PatternTypeConfig = TiledPatternConfig | OutlinedPatternConfig` (`types.ts:879`).
The discriminant is `type`: `'outlined'` means outlined, anything else means tiled.

**To switch pattern, write the whole object** to `patternTypeConfig`. The UI does
the same: it writes `tiledPatternConfigs[id]` (`src/components/pattern/PatternTileButton.svelte:23-45`)
or `defaultOutlinedPatternConfig()` (`PatternView.svelte:140`). Switching drops
`labels`. Built-in tiled configs are in `tiledPatternConfigs` (`shades-config.ts:305`).

| `tiledBoxPattern-0`              | quadrilateral | tessellation "Box"    |                                                                                                                                                                                                                |
| `tiledGridPattern-0`             | quadrilateral | legacy                | `variant: 'rect'\|'triangle-0'\|'triangle-1'`, `dropEdgeSegments`.                                                                                                                                             |
| `tiledHexparquetPattern-0`       | quadrilateral | legacy                | Cycles through subunits. `keepPartnerSeam`. Row/column controls are hidden in the UI.                                                                                                                          |

### Labels: `patternTypeConfig.labels` (`PatternLabelsConfig`, `types.ts:751`)

Lengths are in **mm**. They are converted to pattern units through
`patternConfig.pageLayout.pageScale` (`src/lib/cut-pattern/label-units.ts`).

| Path                                                                    | Default                         | Meaning                                                                                     |
| ----------------------------------------------------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------- |
| `patternTypeConfig.labels.units`                                        | `'mm'`                          | Keep it `'mm'`. If it is absent, the load migration treats the values as old pattern units. |
| `patternTypeConfig.labels.selfTag.enabled`                              | false (tiled) / true (outlined) | Band address tag.                                                                           |
| `patternTypeConfig.labels.selfTag.externalTag`                          | true                            | Callout with a stem, outside the band.                                                      |
| `patternTypeConfig.labels.selfTag.height`                               | 21                              | Font height (mm).                                                                           |
| `patternTypeConfig.labels.selfTag.angle`                                | 0                               | Offset added to the automatic angle.                                                        |
| `patternTypeConfig.labels.selfTag.padding` / `stemLength` / `stemWidth` | 15 / 30 / 6                     | mm.                                                                                         |
| `patternTypeConfig.labels.onTab`                                        | `{enabled:false, padding:1.5}`  | Labels drawn on tabs.                                                                       |

`labels` may be missing after a pattern switch. Set the whole `labels` object,
because the bridge cannot create `labels.selfTag.enabled` when `labels` doesn't
exist.

## `cutoutConfig` (top level)

`CutoutConfig` (`types.ts:227`), part of the legacy globule cutout system.
Default `defaultCutoutConfig()[1]` (`shades-config.ts:744`). Projection and Voronoi
patterns do not use it.
